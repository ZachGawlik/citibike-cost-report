# Citi Bike Cost Report

Citi Bike rides in NYC/NJ will get capped to $3.65 starting January 19, 2027. https://citibikenyc.com/memberebikecap

This code calculates a report of how much money this fare cap would have saved you over your past year of Citi Bike usage.

## How to use it

1. Log in at <https://account.citibikenyc.com/ride-history>.
2. Open your browser's DevTools console. In most browsers: right-click
   anywhere on the page and select "Inspect". Click the "Console" tab of the pane.
3. Copy the whole contents of `citibike-ride-costs.js`, paste it into the console's input and
   press Enter.
4. Wait a few seconds while it fetches your rides. You'll see a few
   `request …` lines, then a table of results.
5. To get the full list of rides, type `copy(citibikeRides.csv)` into the
   console and press Enter. That puts it on your clipboard as CSV, which you
   can paste into a spreadsheet (Google Sheets, Excel, Numbers).

## Is it safe?

Just like all software, you should only run code from sources you trust.
The script's code was written to be as readable as possible for that reason.

This script fetches your ride history in the same way that the webpage itself does.
This data only exists within your browser tab and is not sent anywhere.
The only Citi Bike provided way to get your extensive ride history is to
repeatedly scroll down and click "Show More" to get merely 10 more entries in your ride history.
This script essentially runs the same underlying data fetches as many "Show More" clicks.

It would be very easy for Citi Bike to offer a native way to retrieve your full ride history.
Unfortunately, for-profit tech companies increasingly lock down your data rather than empowering you to review it yourself.

## What you get

**A table** with one row per month, plus a `total` row at the bottom:

| column          | meaning                                          |
|-----------------|--------------------------------------------------|
| `rides`         | how many rides started that month                |
| `total`         | what you actually paid                           |
| `rides > $3.65` | how many rides cost more than $3.65              |
| `capped total`  | what you'd have paid if no ride cost over $3.65  |
| `saved`         | the difference between the two                   |

The first and last months only cover part of the month, because the period is
exactly the last 365 days.

**The ride list** (from `copy(citibikeRides.csv)`), one ride per line, oldest
first:

| column        | example               | meaning                          |
|---------------|-----------------------|----------------------------------|
| `start`       | `2026-11-20 16:27:14` | when the ride started (New York time) |
| `minutes`     | `6`                   | how long it lasted               |
| `cents`       | `176`                 | what it cost, in cents ($1.76)   |
| `cappedCents` | `176`                 | what it would cost with the cap  |
